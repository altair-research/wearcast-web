Web / Android · iPhone

친구 피드백은 웹 체험판으로 함께해요. 설치 파일 없이 같은 링크에서 새 버전을 확인할 수 있어요.

웹으로 바로 시작하기↗
  1. Android는 Chrome, iPhone은 Safari로 열어요.
  2. 원하면 브라우저 메뉴나 공유 버튼에서 ‘홈 화면에 추가’를 선택해요.
  3. 예전 화면이 보이면 앱을 다시 열거나 새로고침해 주세요.

홈 화면 아이콘으로 앱처럼 열 수 있어요. 웹에서는 예약 알림과 홈 위젯을 제공하지 않아요.

↓

Android APK

1.0.30+31

알림과 홈 위젯을 확인하고 싶은 Android 사용자용 테스트 앱이에요.

테스트 APK 다운로드↓
  1. APK를 다운로드하고 파일을 열어요.
  2. 설치 허용을 묻는 경우, 다운로드한 브라우저나 파일 앱의 설치를 허용해요.
  3. 새 버전은 새 APK를 설치해 주세요. 현재 파일 배포는 자동 업데이트되지 않아요.
다운로드가 안 되면 GitHub에서 받기 ↗

지금은 웹 체험판으로 의견을 모으고 있어요. 향후 앱스토어에 정식 출시하면 스토어를 통해 업데이트받을 수 있어요. 자동 업데이트 여부는 기기 설정에 따라 달라요.

# WearCast web trial

https://altair-research.github.io/wearcast-web/

This repository contains the compiled web application and its runtime assets.
Application source, Android signing files, credentials and user records are not included.
Settings and check-ins stay in each browser. Different web origins have separate storage.
The published JavaScript and images are publicly readable.
Deployment uses GitHub Pages from main, root, with .nojekyll.
